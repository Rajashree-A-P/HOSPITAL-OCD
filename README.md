# 🏥 OCD Patient Data Analysis | SQL Project

# 📌 Project Overview
This SQL project focuses on analyzing OCD (Obsessive-Compulsive Disorder) patient data to identify trends in patient demographics, obsession severity, compulsion severity, diagnosis patterns, and medication usage.

The analysis was performed using SQL queries to transform raw healthcare data into meaningful insights that can support medical research and healthcare decision-making.

---

# 🎯 Project Objectives
- Analyze OCD patient demographics
- Identify common obsession and compulsion types
- Measure severity scores using Y-BOCS metrics
- Track patient diagnosis trends over time
- Analyze medication usage patterns
- Generate healthcare insights using SQL queries

---
